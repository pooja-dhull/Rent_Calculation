# Rent_Calculation
A simple rent calculation using python

## Project Overview
The Rent Calculator is a simple Python project designed to calculate the monthly expenses shared by people living in a rented flat or room.

The program takes rent, food expenses, electricity units, electricity charges per unit, and the number of people as input. It then calculates the total expenses and the amount each person needs to pay.

## Features
- Accepts monthly rent as user input.
- Takes food expenses as input.
- Calculates the electricity bill based on units consumed and the cost per unit.
- Accepts the number of people sharing the expenses.
- Calculates the total bill per person.

## Technologies Used
- Python 3
- Variables and Data Types
- User Input (`input()`)
- Type Conversion (`int()`)
- Arithmetic Operators

## How to Run the Project

1. Clone this repository.
2. Open the project in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python Rent_Calculator.py
```

## Example

**Input:**
- Monthly Rent: 5000
- Food Expenses: 2000
- Electricity Units: 400
- Charge Per Unit: 10
- Number of People: 3

**Output:**

```text
Each person will pay = 3666
```
